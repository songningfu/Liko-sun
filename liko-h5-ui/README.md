# Liko 手机端 H5 UI 原型

这是第一版纯前端页面外壳，专门按 375 / 390px 手机宽度设计，不依赖框架、外部字体或网络资源。

## 查看方式

直接双击 `index.html` 即可在浏览器中查看。建议打开浏览器的手机模拟模式，并选择 375px 或 390px 宽度。

## 当前页面

- **Liko**：默认进入角色主页，可查看年龄、当前状态、人格短句和唯一编号。角色直接复用 `形象设计/liko-animation-demo.html` 的完整 SVG 图层与五状态动画，不再使用关键姿势图模拟动作，也不重新绘制。
- **Chat**：点击“问问 Liko”后在 Liko 页内部进入；大角色会收拢为顶部小头像，并展示高频问题、示例回答、官方来源、复制和好评/差评。
- **我的**：Liko 身份卡、唯一编号、外壳/肤色信息以及设置入口空壳。

底部导航始终只有 `Liko` 和 `我的`。Chat 不是独立底部页面，可通过顶部返回按钮回到角色主页。

## 当前边界

- 不调用任何模型或 API。
- 不保存 API Key；`.gitignore` 已禁止提交本地环境变量文件。
- 输入问题或选择高频问题后只更新页面里的示例问题，并提示当前是 UI 演示。
- 来源链接与设置项只展示交互反馈，后续接入真实页面和数据。
- 好评可撤销；差评原因面板用于演示未来的回答核查流程，当前不上传数据。
- Liko 编号为演示值 `No. 000128`，正式版本由注册顺序生成，与颜色无关。
- 待机、学习、听歌、健身、游戏由系统每 60 分钟自动切换一次，用户不能手动选择；五种状态以随机顺序完整走完一轮后才开始下一轮，相邻状态不会重复。
- 当前原型把状态轮换记录保存在浏览器本地，刷新页面不会重抽。正式版需把状态、剩余顺序和上次切换时间存到后端，保证同一用户在不同设备上看到一致结果。

后续真实模型接入方式见 `API接入说明.md`。
