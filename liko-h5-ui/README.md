# Liko 手机端 H5 UI 原型

这是第一版手机 H5 页面，专门按 375 / 390px 手机宽度设计，不依赖前端框架、外部字体或静态网络资源。页面已经接入 FastAPI 的 SSE、账号密码登录、专属 Liko 与额度接口；服务器配置 PostgreSQL 后即可启用真实账号。

## 查看方式

直接双击 `index.html` 即可在浏览器中查看。建议打开浏览器的手机模拟模式，并选择 375px 或 390px 宽度。

## 当前页面

- **Liko**：默认进入角色主页，可查看年龄、当前状态、人格短句和唯一编号。角色直接复用 `形象设计/liko-animation-demo.html` 的完整 SVG 图层与五状态动画，不再使用关键姿势图模拟动作，也不重新绘制。
- **Chat**：点击“问问 Liko”后在 Liko 页内部进入；大角色会收拢为顶部小头像，并展示高频问题、示例回答、官方来源、复制和好评/差评。
- **我的**：游客额度、账号密码登录/注册、正式 Liko 身份卡、唯一编号、外壳/内层颜色与退出登录。

底部导航始终只有 `Liko` 和 `我的`。Chat 不是独立底部页面，可通过顶部返回按钮回到角色主页。

## 当前边界

- 提问会调用自有后端 `/api/chat/stream`；测试服务器会返回 FastGPT 的真实流式答案和官方来源，本地未配置 FastGPT 时才返回明确的联调占位事件。
- 不保存 API Key；`.gitignore` 已禁止提交本地环境变量文件。
- 后端未启动或网络错误时，页面保留用户问题并明确显示连接失败，不会继续展示与问题无关的示例答案。
- 来源链接已使用后端筛选后的深圳大学官方 HTTPS 地址；设置项仍是交互空壳。
- 好评可撤销；差评原因面板用于演示未来的回答核查流程，当前不上传数据。
- 游客没有正式编号；注册后由后端按顺序生成编号。外壳与内层从完整 sRGB 色域独立随机，自动避开难以分辨的组合并永久绑定账号。
- 待机、学习、听歌、健身、游戏由系统每 60 分钟自动切换一次，用户不能手动选择；五种状态以随机顺序完整走完一轮后才开始下一轮，相邻状态不会重复。
- 当前原型把状态轮换记录保存在浏览器本地，刷新页面不会重抽。正式版需把状态、剩余顺序和上次切换时间存到后端，保证同一用户在不同设备上看到一致结果。

后续真实模型接入方式见 `API接入说明.md`。

## 联调方式

先按 `../backend/README.md` 在 `8001` 端口启动后端，再在仓库根目录启动 `8000` 端口的静态服务：

```powershell
cd backend
.\.venv\Scripts\python -m uvicorn app.main:app --port 8001

cd ..
python -m http.server 8000
```

访问 `http://127.0.0.1:8000/liko-h5-ui/`。本地页面会自动连接 `http://127.0.0.1:8001`；部署环境默认使用同域 `/api`，也可以在页面加载前通过 `window.LIKO_API_BASE` 指定后端地址。
