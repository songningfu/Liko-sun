# Liko 问答 API 接入说明

当前页面已经接入自有后端的 SSE 接口契约。未配置 FastGPT 时，后端返回联调占位且不会把示例内容作为答案；配置完整后，后端会代理 FastGPT 的真实流式问答。

## 安全边界

- H5 不能直接保存或调用 DeepSeek API Key。
- 正确链路是：`手机 H5 → 自有 FastAPI → 自托管 FastGPT → 模型服务`。
- FastGPT 应用 Key 只保存在 FastAPI 的后端环境变量 `FASTGPT_API_KEY`；模型服务 Key 只保存在 FastGPT 部署环境中。两者都不得写进 HTML、JavaScript、`VITE_*`、浏览器缓存或日志。
- 开发、测试和生产使用不同 Key；已经公开发送过的 Key 应撤销后重新生成。

## 第一版建议

- 联调模型：`deepseek-v4-flash`。
- 向量模型：`bge-m3`。
- 默认关闭思考模式，校园常规问答优先追求速度和成本。
- 单次回答建议限制在约 500–800 个输出 token。
- 前端只提交 `conversationId`、`requestId` 和用户问题，不允许前端指定模型、系统提示词或输出上限。
- 后端负责拼接角色提示、历史对话与以后接入的 RAG 检索结果。
- 流式响应只向前端发送 `meta`、`delta`、`sources`、`done`、`error` 等业务事件。

## 当前 SSE 契约

`POST /api/chat/stream` 请求体：

```json
{
  "requestId": "web_...",
  "conversationId": null,
  "message": "校园卡丢了怎么补办？",
  "campus": "粤海",
  "source": "input"
}
```

响应的 `Content-Type` 为 `text/event-stream`：

- `meta`：`requestId`、`conversationId`、`answerId` 和当前运行模式。
- `delta`：增量文本，字段为 `text`。
- `sources`：官方来源数组；无可靠来源时必须为空数组。
- `done`：结束原因与是否允许反馈。
- `error`：可展示的业务错误；不得包含密钥、上游请求头或内部堆栈。

未配置上游时以 `integration_stub` 结束，`canRate` 为 `false`。真实答案成功生成并获得稳定 `answerId` 后才允许提交反馈。FastGPT 的 `flowResponses.quoteList` 会在后端转换为来源；只有 `https://szu.edu.cn` 及其 HTTPS 子域名能够作为校园官方来源返回 H5。

## 开发期保护

- 每个用户同一时间最多一个生成请求。
- 设置每分钟、每天的请求上限和总预算开关。
- 输入限制长度，防止重复点击，超时后允许取消或重试。
- 不默认记录用户完整问题，不在日志中输出 Key 或上游请求头。
- AI 服务不可用时，页面仍应正常显示两页 UI 和已有内容。

## 高频问题与回答反馈

- 用户主动输入的问题与推荐问题点击必须区分记录，推荐点击不能直接累加为自然热度，避免“越推荐越热门”。
- 相似问法先聚合为同一个问题主题，再按照近 7 天独立用户数、时间衰减、答案满意率和来源有效期计算推荐顺序。
- 只推送已有可靠答案、仍有有效来源的问题；校园事务、生活服务、学习资源应保留基本多样性。
- 每条回答使用稳定的 `answerId`。好评/差评记录 `rating`，差评可附带“不准确、已过期、没回答问题、表达不清、来源有问题”等原因。
- 同一用户对同一回答只保留一条反馈，允许修改或撤销；匿名标识由服务端生成，不保存学号。
- 好评/差评用于回答排序、RAG 问题定位和人工核查队列，不直接自动改写事实，也不直接作为训练数据。
- “不准确”或“已过期”必须结合对应引用、知识库版本和官方资料核查后再更新。

## 游客、登录与长期记忆

- 游客无需登录即可正常问答，但只保留当前会话上下文；后续接入额度服务后执行游客限额，不能建立长期人格与偏好记忆。
- 登录后可获得更高额度，并可选择开启“让 Liko 更了解我”。只有开启后，后端才会查询和更新 Mem0 长期记忆。
- 登录身份必须来自服务端会话。前端不得提交一个任意 `userId` 来访问或写入记忆。
- 用户可以通过“Liko 对我的了解”查看、修改、删除单条记忆或清空全部记忆。
- 健康、家庭、财务等内容不按类别自动禁止记忆；开启长期记忆时需要清晰说明可能保存这些内容，并提供关闭与删除能力。
- Mem0 记忆不能作为校园事实来源。后端只把与当前问题相关的少量用户记忆放入 FastGPT 的 `memory_context` 变量，学校政策、日期、费用和地点仍必须来自官方知识库引用。
