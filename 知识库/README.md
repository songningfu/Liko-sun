## 数据原则

- 校园事实优先使用深圳大学官方网页、官方公众号文章或校内部门正式文件。
- 每条资料必须记录校区、发布部门、发布日期、适用时间和最后核验时间。
- 回答必须附来源；没有可靠来源时明确说明，不猜测、不拼凑。
- 不采集或存储学号、手机号、身份证号、个人成绩等敏感信息。
