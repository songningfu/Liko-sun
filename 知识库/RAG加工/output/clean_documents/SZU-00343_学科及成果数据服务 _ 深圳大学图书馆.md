# 学科及成果数据服务 | 深圳大学图书馆

（1）学术数据服务
图书馆在“学术数据服务”网站上定期提供以下数据：ESI数据监测、深圳大学主要成果收录月度统计、ESI学科院系贡献度、ESI高被引论文数据、人才评价榜单数据、重要期刊列表数据等。
- ESI数据监测：自2019年9月起，图书馆基于科睿唯安的InCites、ESI、JCR、SCIE等数据库，每两个月提供四份ESI学科分析报告，分别是《深圳大学ESI前1%学科数据简报》、《深圳大学ESI学科潜力值监测快报》、《深圳大学ESI在广东省的表现及与对标高校的对比分析》、《深圳大学ESI高被引论文学术表现快报》。
- 深圳大学主要成果收录月度统计：每月提供深圳大学的SCIE、SSCI、A&HCI、CPCI-S（理工）、EI、CSSCI论文数据和各ESI学科论文数据。
- ESI学科院系贡献度：图书馆每两个月提供我校已进入ESI学科的学院贡献度表格数据。
- ESI高被引论文数据：提供2016年9月以来我校的ESI高被引论文、热点论文数据。
- 人才评价榜单数据：提供科睿唯安全球高被引学者、Elsevier“中国高被引学者”榜单、斯坦福全球前2%顶尖科学家榜单数据。
- 重要期刊列表数据：提供ESI学科期刊列表、自然指数期刊列表、中国科技期刊卓越行动计划期刊列表。

（2）成果数据统计分析服务
以门户平台、WOS、Scopus等平台为基础，图书馆能为职能部门、学院院系、学者提供多元化的成果数据统计及分析服务。
- 基础数据服务：通过制定检索策略、设计检索式、限定约束条件，从数据库平台直接下载后提供标准格式数据。
- 增值数据服务：通过图书馆已开发平台、知识加工流程等，提供支持全校学术成果更新、院系年度考核、教师年度考核、职称评审、学院发展性评估等需求的标准化模板数据。
