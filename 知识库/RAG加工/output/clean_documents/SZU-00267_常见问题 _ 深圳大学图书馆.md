### 关于读者证
- 问 ：使用 自助借书机 时，提示我的读者证是无效卡，怎么回事？ 答 ：可能是因为有逾期未还图书，或有违约记录，找总服务台借还书处老师查询处理。
- 问 ：使用 自助借书机 时，提示“卡挂失”，怎么办？ 答 ：在总服务台查询卡状态是否正常，若正常，则可能是因为校园卡中心数据库暂时没有更新，请到 校园卡中心 处理。
- 问 ：读者证的个人密码忘记了，怎么办？ 答 ：由本人携带证件（身份证和校园卡）到深圳大学 校园卡中心 办理手续，重置密码。
- 问 ：我的 校园卡 刷不了门禁入馆，怎么回事？ 答 ：请在门卫处查询，如有疑问，请到办证处（北馆二楼207室、丽湖馆二楼A202）找老师查询。
- 问 ：我的读者证显示已暂停，怎么回事？ 答 ： 可能有违约记录 ，请到办证处（北馆二楼207室、丽湖馆二楼A202）找老师查询。
- 问 ：我的校园卡丢了，怎么办？ 答 ：请立即前往 校园卡中心 办理挂失和补办手续。
- 问 ：我的读者证丢了，刚补办了一张新卡，怎么进图书馆读不了卡了？ 答 ：请在办证处（北馆二楼207室、丽湖馆二楼A202）找老师读卡激活即可。
- 问 ：我原来在图书馆办证时交的借书押金可以退吗？ 答 ：可以。请持本人读者证和押金收据（若押金收据丢失需带本人身份证原件及双面复印件），在图书馆办证处（北馆二楼207室）办理退证及押金清退手续，然后前往校财务大厅领取押金。如有疑问，请致电2653 6272 咨询。

### 校友或校外读者
- 问 ：毕业后还能使用图书馆资源吗？ 答 ：毕业后可以办理 校友卡 ，凭校友卡在门卫处登记。经允许后，可进入图书馆。 需刷校园卡进入的阅览室，请校友向值班人员提出申请，经同意后进入。 校友可使用休闲座位。图书馆阅览室内有编号的座位采用计算机座位管理系统进行选座。因校友卡不能选座，所以请校友使用阅览室内外未编号的休闲座位。如因占用阅览室内的编号座位而发生冲突，请校友把座位礼让给选座的读者。 本馆暂不向校友提供借书、借刊等外借服务，敬请谅解。 如有疑问，请向总服务台咨询（参见 联系我们 ）。
- 需刷校园卡进入的阅览室，请校友向值班人员提出申请，经同意后进入。
- 校友可使用休闲座位。图书馆阅览室内有编号的座位采用计算机座位管理系统进行选座。因校友卡不能选座，所以请校友使用阅览室内外未编号的休闲座位。如因占用阅览室内的编号座位而发生冲突，请校友把座位礼让给选座的读者。
- 本馆暂不向校友提供借书、借刊等外借服务，敬请谅解。
- 问 ：校外人员可以进深大图书馆借书和使用电子资源吗？ 答 ：因 不对校外人员办证 ，所以校外人员无法借书和 使用电子资源 。 可使用的资源请查看 知识开放平台 。
- 问 ：校外人员是否可申请文献传递？ 答 ：因财务原因，不予受理，敬请谅解！

- 问 ：哪些数据库可以出具引用证明？ 答 ：SCI、SSCI、A&HCI、CSSCI、CSCD都可以出具引用证明。
- 问 ：SCI论文刚刚发表，能不能开论文收录引用证明？ 答 ：若只刚刚online，不要着急，等论文被权威库SCI-E收录后才可以开论文收录引用证明。可向相关评审部门咨询是否可通过论文+期刊分区证明来佐证。
- 问 ：我是共同第一作者或共同通讯作者，论文收录引用证明里反映不出来怎么办？ 答 ：请进入“ 深圳大学图书馆查收查引系统 ”，将论文导入，点击系统右上角的“联系馆员”，将论文全文以附件形式发送给馆员，并备注共同第一或共同通讯。我们会在核对后出具证明。
- 问 ：可以给我出高被引论文或热点论文证明吗？ 答 ：可以，我们的论文收录引用证明里会标注出高被引论文或热点论文。
- 问 ：校外人员是否可以申请出具论文收录引用证明？ 答 ：本服务仅面向深大师生。即将入职深大的教职工可由其他深大教师代为申请，但证明中的作者单位必须是深圳大学**学院。
- 问 ：提交论文收录引用证明申请后，什么时候可以取证明？ 答 ：申请委托提交后可自行在系统上查看委托处理状态。一般在3-5个工作日内完成。 其他相关咨询，可拨打咨询电话：0755-2653 7002 （校内分机：87002）。
### 文献传递
- 问 ：本馆没有收藏的纸质或电子文献，可以通过什么途经获取？ 答 ：可以通过 文献传递 获取，主要途径有荔园学术搜索、深圳文献港和CALIS系统等。
- 问 ：本校师生通过文献传递获取的文献，需要缴费吗？ 答 ：文献传递有几个途径，荔园学术搜索、深圳文献港是免费的，CALIS和CASHL等系统的收费标准以服务馆规定为准（一般文献0.3元/页），本馆根据专项经费情况给予一定额度的补贴。
### 推荐资源
- 问 ：如何申请试用或推荐采购电子资源？ 答 ：读者出于教学、科研的需要，希望图书馆组织试用或采购本馆未拥有的电子资源，请在“图书馆主页 > 资源 > 数据库 > 申请试用 ／ 推荐采购 ”页面下载、填写《深圳大学图书馆电子资源试用申请表》或《深圳大学图书馆电子资源荐购申请表》，打印后请学院老师签字、学院领导签字盖章，然后将纸质申请表送交图书馆北馆513室或发送扫描的电子版至邮箱 zuosn@szu.edu.cn 。 图书馆接到试用申请后，向电子资源供应商申请试用。若得到批准，图书馆将组织该电子资源的试用。 图书馆接到荐购申请后，将进行论证，在通过论证且经费允许的情况下采购此电子资源。 更多信息请咨询图书馆电子资源部，电话：0755-2653 4322 （校内分机：84322）。
- 图书馆接到试用申请后，向电子资源供应商申请试用。若得到批准，图书馆将组织该电子资源的试用。
- 图书馆接到荐购申请后，将进行论证，在通过论证且经费允许的情况下采购此电子资源。

- 问 ： 自助借书机 怎么使用？ 答 ：开通借书功能后才能使用。借书过程只需读卡/刷校园码、验证、放书等步骤即可轻松完成。如有疑问，请咨询总服务台老师。

- 问 ：图书馆是否提供打印服务？ 答 ：目前图书馆不提供打印服务。
- 问 ：图书馆提供文献扫描服务吗？ 答 ：在丽湖校区启明楼（丽湖馆）二楼大厅咨询台对面设置有高清扫描仪，可供读者自行扫描文献资料。 简单操作流程如下（详细操作流程参见现场操作介绍视频） 打开“录典书刊扫描管理系统”；选择图像采集功能；设定分辨率、文件格式、存储路径等参数。 按下展平压架固定文稿；按拍摄按钮采集当前双页图像。 选择图像处理功能，勾选裁切、纠偏、边缘填充等选项；系统自动处理后，选择快捷输出；选择文档格式（如双层PDF、TXT等），系统自动导出。 扫描仪使用基本规范 禁止整本或大量扫描，单册文献扫描复印量不得超过其篇幅的三分之一； 禁止传播扫描件； 扫描件仅限个人研究学习或其他非盈利目的使用； 港台图书一般不允许扫描； 更多信息请参考《 深圳大学图书馆保护著作权复印条例 》。
