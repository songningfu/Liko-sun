# 深圳大学学术门户 | 深圳大学图书馆

通过建设深圳大学学术门户，图书馆采集全校建校以来的中外期刊和会议论文、专利、著作等成果数据，并对数据进行组织、关联、清洗、归属、统计。学术门户系统保存、管理和揭示深圳大学科研成果，旨在促进学术交流，提升深圳大学及学者的学术影响力。
深圳大学学术门户提供“院系”、“学者”、“成果”三大基本功能平台。
- 院系平台：按院系展现科研成果，提供各院系的成果产出统计数据。
- 学者平台：按学者展现其科研成果，动态追踪学术成果收录、引用等情况，可视化揭示学者学术科研网络，提供计量评价分析报告。
- 成果平台：总体展现深圳大学科研成果，目前含期刊论文、会议论文、学位论文、专利、标准、专著等。
深圳大学学术门户仅限校内教师访问，欢迎大家登录利用。
