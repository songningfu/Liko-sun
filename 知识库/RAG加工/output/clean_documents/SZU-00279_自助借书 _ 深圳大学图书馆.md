# 自助借书 | 深圳大学图书馆

各馆（即：粤海校区北、南馆，丽湖校区中央图书馆）二楼大厅总服务台旁均设有自助借书机，以便读者自助办理借书手续。
### 作用
自助借还书系统是替代传统人工服务、手工借还书的图书自动流通工具。使用自助借还书系统，读者可以自行办理书刊资料的借阅和归还手续，而无需通过图书馆馆员的服务。自助借还书系统的优越性是在图书馆有限的人力资源下，简化借还手续、提高流通效率、分散柜台服务量、减少读者排队等候的时间、保证读者隐私、提高服务品质，更好地体现现代化图书馆的人性化管理，提高读者满意度。
### 使用方法
凡持有已开通图书外借功能的校园卡的读者均可使用自助借书机借书。自助借书机操作简单，触摸屏按键，方便快捷。
本馆自助借书机只开通读者自助借书业务，还书请到总服务台借还书处。
### 操作步骤
- 点击【借书】按钮。
- 在指定位置刷校园卡，并输入校园卡密码；或刷深圳大学校园码。
- 把借阅图书放置在指定区域并选择借阅数量（如超出5本，请分多次借阅。多出的图书请远离图书放置区）。
- 确认借阅图书信息与数量，并点击【确认借阅】。
- 借书完成，请取走图书。
### 温馨提示
- 确认自己的卡处于“正常”状态。
- 输入密码时，注意保护勿泄露。
- 某些图书会被自助机拒借，请到总服务台办理。
- 借书完毕，切记取走校园卡和成功办理借书手续的图书。
