# 深圳大学本科生录取及邮寄查询
温馨提示：
1.正确输入身份证号（华侨为中国护照号）、考生号及姓名，才可准确查询。
2.考生号为14位（**广东省需在考生号前添加 “2644”，“26**”指2026年，“44”为广东省代码，其他生源地代码见下图**** ），华侨港澳台联招、香港中学文凭考试招生的考生号为9位准考证号，台湾学测、澳门保送生、港澳自主招生（含香港学院）考生号为10位身份证号（含括号，注意为英文/半角格式符号）。
3.**录取结果以收到的录取通知书为准， 邮寄信息待邮寄前统一更新**。录取通知书（第一批）已于8月5日寄出，第二批（四川普通类、西藏、新疆预科）已于8月7日寄出，港澳自主招生预计于8月中旬邮寄。
备注：
1.深圳大学2026级本科新生，报到日期为2026年9月5日，报到日期及地点以入学须知为准。
2.深圳大学2026级本科新疆预科新生报到地点为粤海校区，报到日期为2026年9月5日，以入学须知为准。
