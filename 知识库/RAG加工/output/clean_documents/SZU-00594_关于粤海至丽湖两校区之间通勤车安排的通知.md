# 关于粤海至丽湖两校区之间通勤车安排的通知
### 作者： 来源： 浏览数：209 发布时间：2025-02-18 09:19
全校各单位：
根据学校开学工作的安排，结合师生返校情况，从2月19日（星期三）起，粤海至丽湖校区之间通勤班车恢复运行，运行时间仅为工作日，两校区教职工和信使人员优先乘坐通勤班车。粤海校区发车地点为汇光楼(光电子研究所)与汇真楼(实验楼)之间的机动车道，丽湖校区发车地点为惟新门。具体发车时间如下：
