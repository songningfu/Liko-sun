# 后勤概况-深圳大学后勤保障部

1983年，深圳大学建校，成立总务处，负责学校后勤事务。后来更名为生活服务总公司、总务处、后勤处、后勤部等。2021年1月，学校合并后勤部、基建部两部门职能，成立了后勤保障部。后勤保障部代表学校全面负责校园基础建设、后勤服务与保障的各项管理职能。
后勤保障部围绕学校发展中心任务，服务学校教学科研需要，贴近师生向往美好生活的要求，守初心、担使命、强监管、精服务，为学校高水平大学建设提供有力支撑。后勤保障部以“服务师生，精益求精”为理念，将“全员育人、全程育人、全方位育人”贯穿后勤保障工作中，努力打造“平安后勤、高效后勤、绿色后勤、智慧后勤、廉洁后勤”。学校是全国文明校园、全国十大最美校园、广东省绿色学校、广东省第一批节水型高校。
