# 深圳大学图书馆保护著作权复印条例 | 深圳大学图书馆

- 根据《中华人民共和国著作权法》、《中华人民共和国著作权法实施条例》，本馆所提供的读者复印服务必须本着尊重任何个人、社会团体或机构享有的著作权，严禁整本复印馆藏印本文献。
- 本馆只提供出于学习、研究或欣赏等非盈利性教育目的的复印。对馆藏图书、期刊、学术论文等印本文献进行复印时，单册文献复印量不得超过其篇幅的三分之一。
- 馆藏印本文献只提供馆内复印。
- 港台图书一般不允许复印。
- 内部资料的复印须经馆长批准 ，严禁私自复印。
