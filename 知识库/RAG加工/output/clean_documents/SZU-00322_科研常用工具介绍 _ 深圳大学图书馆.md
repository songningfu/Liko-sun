# 科研常用工具介绍 | 深圳大学图书馆

在学术研究和论文写作中，高效的数据处理和清晰的可视化是展示成果、增强说服力的关键。为了帮助大家更好地了解和选择合适的工具，本页面精选并介绍了一系列主流的科研常用工具。
- 一、数据处理与分析工具 Excel/WPS表格、Python、R语言
- 二、文献处理与分析工具 Incites-Research Horizon Navigator、EndNote、NoteExpress、ESI、JCR
- 三、数据可视化工具 CiteSpace、VOSviewer、Excel/WPS表格、Xmind
- 四、人工智能辅助工具 AI表格数据分析、AI编程辅助工具、通用型AI工具
### 数据处理与分析工具
此类工具专注于数据的清洗、整理、转换和统计分析。
- Excel/WPS表格 作为最基础且广泛使用的数据处理工具，Excel/WPS表格以其强大的数据整理、统计分析和可视化等功能，成为无数人的日常利器。通过其内置的函数和插件，用户可以轻松完成从简单的表格计算到复杂的数据分析任务。
- Python Python作为数据科学领域的“万能钥匙”，拥有丰富的子库（如Pandas、NumPy、Matplotlib等），能够进行数据清洗、统计分析、构建机器学习模型。其简洁的语法和高效的性能，使其成为数据分析与处理的首选。
- R语言 R语言由Ross Ihaka和Robert Gentleman于1993年在新西兰奥克兰大学开发，以其强大的统计和图形功能，特别适合进行高级数据分析和数据可视化，内置了大量的统计模型和算法，可用于复杂的数据分析和建模，涵盖丰富的包（packages）和灵活的编程环境，在生物信息学、金融分析、市场研究等领域有广泛应用。
### 文献处理与分析工具
- Incites-Research Horizon Navigator 科睿唯安推出的科研评价参考工具，用于实时跟踪、分析和对比机构与个人的研究产出及影响力。这款工具专注于识别和分析新兴研究主题，帮助研究人员掌握学术前沿动态，揭示新兴主题如何在不同领域形成与发展，优化研究方向。通过大数据分析，Incites能够揭示学术趋势，为科研决策提供有力支持。
- EndNote ENDNOTE®文献管理软件是科睿唯安公司开发的旗舰型文献管理系统，至今已有二十余年历史，最新版本为20版（第二十版）。（mac系统安装包目前最新版本为X9版）。ENDNOTE®单机版将检索、分析、管理、写作、投稿整合在一起，创建简单工作流，使之成为一个重要研究、管理、写作和发表工具。 通过ENDNOTE®单机版，研究人员可以： 轻松地获取科技文献，建立个人文献数据库； 对科技文献进行有效的管理和分析，激发科研思路； 撰写论文时，采用期刊投稿模板，提高论文写作效率； 边写作边引用参考文献，并可一键调整参考文献格式； 跨平台无缝整合，同步文献，随时随地获取科技信息。 使用指南： EndNote202105新手上路.pdf 、 EndNote_使用指南（2025版）.pdf

- 对科技文献进行有效的管理和分析，激发科研思路；

- NoteExpress NoteExpress是目前流行的参考文献管理工具软件，其核心功能是帮助读者在整个科研流程中高效利用电子资源：检索并管理得到的文献摘要、全文；在撰写学术论文、学位论文、专著或报告时，可在正文中的指定位置方便地添加文中注释，然后按照不同的期刊，学位论文格式要求自动生成参考文献索引。 其核心功能如下： 检索：支持数以百计的全球图书馆书库和电子数据库，如万方、维普、期刊网、Elsevier ScienceDirect、ACS、OCLC、WOS、Ei、美国国会图书馆等。一次检索，永久保存。 管理：可以分门别类管理百万级的电子文献题录和全文，独创的虚拟文件夹功能更适合多学科交叉的现代科研。 分析：对检索结果进行多种统计分析，从而使研究者更快速地了解某领域里的重要专家、研究机构、研究热点等。 发现：与文献相互关联的笔记功能，能随时记录阅读文献时的思考，方便以后查看和引用。检索结果可以长期保存，并自动推送符合特定条件的相关文献，对于长期跟踪某一专业的研究动态提供了极大方便。 写作：支持Word和Latex，在论文写作时可以随时引用保存的文献题录，并自动生成符合要求的参考文献索引。软件内置3,000种国内外期刊和学位论文的格式定义。首创的多国语言模板功能，可以自动根据所引用参考文献语言不同差异化输出。
- 检索：支持数以百计的全球图书馆书库和电子数据库，如万方、维普、期刊网、Elsevier ScienceDirect、ACS、OCLC、WOS、Ei、美国国会图书馆等。一次检索，永久保存。
- 管理：可以分门别类管理百万级的电子文献题录和全文，独创的虚拟文件夹功能更适合多学科交叉的现代科研。
- 分析：对检索结果进行多种统计分析，从而使研究者更快速地了解某领域里的重要专家、研究机构、研究热点等。
- 发现：与文献相互关联的笔记功能，能随时记录阅读文献时的思考，方便以后查看和引用。检索结果可以长期保存，并自动推送符合特定条件的相关文献，对于长期跟踪某一专业的研究动态提供了极大方便。
- 写作：支持Word和Latex，在论文写作时可以随时引用保存的文献题录，并自动生成符合要求的参考文献索引。软件内置3,000种国内外期刊和学位论文的格式定义。首创的多国语言模板功能，可以自动根据所引用参考文献语言不同差异化输出。
- ESI Essential Science Indicators（基本科学指标）是汤姆森科技信息集团在汇集和分析Web of Science（SCIE/SSCI）所收录的学术文献及其所引用的参考文献的基础上建立起来的分析型数据库，仅其中对所有被引用过的文献进行分析。通过Essential Science Indicators，研究人员可以系统地、有针对性地分析国际科技文献，从而了解一些著名的科学家、研究机构（或大学）、国家（或区域）和学术期刊在某一学科领域的发展和影响；同时科研管理人员也可以利用该资源找到影响决策分析的基础数据。 ESI数据中，“Highly cited papers”基于最近十年的数据滚动统计，“hot papers”基于最近两年的数据滚动统计。数据定期更新。
- JCR JCR期刊引文分析报告，包括：JCR Web Science Edition和JCR Web Social Science Edition应用引文分析方法及各种量化指标。JCR系统地分析自然科学和社会科学领域内各个学科学术期刊的相对重要性。Web of Science与JCR on Web连接在一起，可以帮助研究人员迅速了解科学研究的相对影响，为科研绩效的评价提供了一定程度的定量依据。
### 数据可视化工具
此类工具能将复杂的数据转化为直观的图形，清晰地呈现关系、趋势和洞见。
- CiteSpace CiteSpace是一款用于科学文献分析和知识图谱构建的工具，支持从主要来源（如Web of Science，Scopus，Dimensions，CNKI，CSSCI和其他一些来源）检索的书目和引文数据。能够把文件之间的关系，用科学知识图谱的方式可视化地展现，帮助用户发现研究热点和趋势。通过可视化文献引用网络，CiteSpace助力研究者洞察学术发展的脉络。目前有基础版（免费版本）可供下载使用。
- VOSviewer VOSviewer专注于构建和可视化科学知识图谱，适用于分析学术文献中的共引关系和关键词共现。其直观的可视化效果，帮助用户快速理解复杂的学术网络。
- Excel/WPS表格 除了数据处理，Excel/WPS表格同样具备强大的可视化功能，支持制作柱状图、折线图、饼图等多种常见图表。通过其灵活的图表工具，用户可以轻松将数据转化为直观的视觉呈现。
- Xmind Xmind是一款思维导图软件，适合进行头脑风暴、项目规划和数据整理。通过图形化方式展示复杂信息，Xmind帮助用户理清思路，提升工作效率。目前Xmind并不是完全免费的，用户可以在试用模式下体验大部分思维导图功能。
### 人工智能辅助工具
随着AI及多模态模型的迅猛发展，越来越多的AI工具能够进行数据分析和可视化，极大简化数据分析和可视化的工作流程。举例如下，深圳大学图书馆目前不提供对下列工具的访问与应用支持。
- AI表格数据分析 目前有多个AI工具可以提取表格数据，并对数据进行分析处理，具体可查看AIGC工具导航- Gen AI工具导航 - GenAI办公、学习助手 的表格制作板块，但这些工具不是完全免费的，具体参照工具说明。
- AI编程辅助工具 对于需要使用Python、R等语言进行数据处理的用户，AI编程工具能够极大提升编码效率，辅助完成代码编写、调试和优化。代表性工具如 Trae （字节开发）、 GitHub Copilot 、 Cursor 等，它们可以作为IDE插件或独立的编辑器，提供智能代码补全、代码生成与解释、Bug修复等功能，但这些工具不是完全免费的，具体参照工具说明。
- 通用型AI工具 除上述AI数据分析工具，各类通用型AI工具，例如DeepSeek、Kimi、豆包、千问大模型、文心一言等也可协助进行数据处理与分析，但这些工具不是完全免费的，具体可查看 AIGC工具导航 。
