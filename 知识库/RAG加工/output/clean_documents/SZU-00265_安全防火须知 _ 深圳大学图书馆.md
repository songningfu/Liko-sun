# 安全防火须知 | 深圳大学图书馆

- 安全高于一切；保护馆藏，人人有责。
- 群策群力，消灭火灾隐患。
- 阅览室、机房、公共场所严禁吸烟。
- 严禁使用明火加热器具。
- 严禁携带易燃易爆物品入馆。
- 随时清理废纸等可燃物品。
- 保护电器，发现隐患立即报请电工维修。
- 严禁在电器附近堆放可燃物品。
- 保护消防器具、装置及水源。
- 严禁堵塞安全通道，防火卷帘门下严禁滞留及堆放物品。
- 严禁私接电线。
- 违反以上规定者处以重罚。
- 一旦发生火警，切记不要慌乱，听从管理人员指挥，有秩序地通过安全通道撤离，防止拥挤、碰撞和跌倒。千万不要使用电梯！
