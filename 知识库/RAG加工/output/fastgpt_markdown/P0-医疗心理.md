| 辅导员发展中心 | 负责辅导员的配备、培训、考核、评优表彰及先进人物和典型事迹的推广宣传，组织辅导员素质能力比赛，培育骨干辅导员工作室，推进辅导员职级职称晋升，开展辅导员队伍团建活动等。 |
| [学生就业指导中心](https://jobszu.jysd.com/) | 负责为学生提供招聘信息、就业政策、职业生涯规划、求职指导等方面的指导与服务，为用人单位提供本校毕业生资料、招聘信息发布与宣传、组织安排各类招聘洽谈活动、支持和配合企业在校园开展雇主品牌活动等服务，开展校企合作活动等。 |
| 学生资助中心 | 负责推动落实各项资助政策；全校全日制本科生和研究生的资助工作，包括奖学金、助学金、勤工助学/三助一辅、大学生医保、困难认定、临时困难补助、绿色通道、国家助学贷款等；开展资助政策宣传和大学生诚信教育；开展资助育人工作。 |
| “一站式”学生社区支持中心 | 在深圳大学”一站式“学生社区综合管理模式领导小组领导下，负责深圳大学”一站式“学生社区综合管理模式建设的支持保障工作；负责学生住宿整体规划；负责学生”一站式“事务服务；组织书记下午茶等师生交流活动；协调相关部门进行毕业生离校审核，协调合作部门做好事务服务中心线下业务办理，学生住宿调配，学生事务服务，师生交流活动等。统筹安排住楼辅导员工作用房及社区值班；统筹协调各学院做好社区学生纪律及秩序管理、假期留校学生管理，及“深大百科”线上事务服务等。 |
| 民族学生工作办公室 | 负责少数民族学生思想政治教育，预科生培养，组织各类民族团结进步主题校园活动，家校联络等。 |
| [心理健康教育与咨询中心](https://xinli.szu.edu.cn/) | 负责面向全体深大在校生开展心理健康教育与咨询服务，促进学生身心健康发展。具体工作内容包括开展个体心理咨询（面谈、网络、24小时电话）、团体心理辅导、心理工作坊、心理健康普查服务；开设心理健康课程（《大学生心理健康》MOOC、《人际关系与成长》、《情绪管理》、《精神健康急救》）；开展心理危机干预、个体及团体督导工作；面向专兼职咨询师、学工队伍、心理委员等开展专业培训；开展系列心理健康宣传活动；指导各学院（部）心理辅导站开展心理健康教育工作；开展心理健康教育课题研究等。 |
