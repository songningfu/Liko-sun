# Liko RAG 数据加工

本目录把深圳大学公开网页的原始 Markdown 加工为可检索的知识库资料。

## 自动完成的工作

- 去除各网站重复出现的菜单、页脚、面包屑和空链接。
- 排除清洗后无正文的技术空页。
- 对完全相同的正文去重，并记录被保留文档编号。
- 标注主题、校区、人群、资料类型、时效和高风险字段。
- 按 Markdown 段落和标题分块，不在句子中间盲目切断。
- 输出 FastGPT 可导入 Markdown、CSV、结构化 JSONL 和首批问题候选来源。

## 运行

```powershell
python process_rag.py
```

结果写入 `output/`。脚本只读取采集器原始数据，不会修改原始网页和附件。

## 重要边界

- 用户已确认官方采集资料可以默认通过，因此程序不再设置逐页人工审批。
- 纯导航空页、正文完全重复页仍会技术排除，避免污染检索。
- 时效、费用、地点、电话、专业代码等内容会保留风险标签；实际回答时仍须显示官方原文并优先采用更新来源。
