## 当前实现边界

- H5 已接入 FastAPI 的 SSE 接口；测试服务器后端已代理真实 FastGPT 流式回答与官方来源，未配置上游时仍会返回明确的占位事件。
- 测试服务器已部署 H5、FastAPI 和自托管 FastGPT PgVector 版；已配置 `deepseek-v4-flash`、`bge-m3`、首轮 7 份知识文件和后端专用 API Key，并完成端到端问答验证；前 3 条标准问题冒烟评测均返回答案与来源事件。
- 账号密码登录、30 天服务端会话、一次性恢复码、游客/登录额度、注册顺序编号、游客随机配色和注册赠送一次自选配色均已部署到测试服务器。账号数据使用独立 PostgreSQL；登录用户的多轮对话会按账号保存，可从 Chat 右上角的 Liko 历史入口重新打开或逐条删除。
- Mem0 OSS、独立 PgVector 与“Liko 对我的了解”管理页均已上线，长期记忆已通过写入、检索、用户隔离、修改和删除的真实链路验收并正式启用；姓名等明确个人资料会走确定性记忆问答，不交给校园知识库猜测。
- Liko 使用正式 SVG 分层动画；五种状态每 60 分钟自动轮换，一轮内不重复。
- 用户编号按注册顺序生成，与外壳色和肤色无关。
- 正式 API Key 只能保存在后端环境变量中，不能写入 H5。
- 知识工厂已部署到测试服务器并保持仅本机访问；已配置 FastGPT 数据集连接与可选模型加工，支持超过内置 12 站继续扩展官网种子、人工文字资料、四级来源可信度，以及 FastGPT 暂存/发布/回滚；自动采集不等于无审核自动上线。
- FastGPT 已正式发布 `style_context` 与 `memory_context` 两个外部变量；Liko 后端会传入已发布的表达习惯，长期记忆仅在 Mem0 完成配置且用户同意后传入。
- Chat 的“大家都在问”已接入近 7 天匿名热度排序：自然提问高权重、推荐卡点击低权重，至少两个不同账号问过且能识别为校园主题时才会进入推荐；样本不足时回退到常用校园问题，避免暴露个人提问或形成自我强化。
- Chat 支持最多 3 个短期附件：文档在后端提取文字，图片由可选视觉模型客观识别后再交给 Liko；原始文件不落盘，提取结果默认 24 小时过期。附件属于用户提供的参考资料，不冒充深圳大学官方来源。
- 统一管理后台已部署到测试服务器，可通过 `http://43.161.217.43/admin/` 使用独立管理员账号登录，查看 Liko 聚合运行数据并操作知识工厂；测试 IP 的 HTTP 入口只用于临时验收，正式使用前必须启用 HTTPS 并更换管理员密码。
- 社交、匹配、好友和对象推荐留到后续版本。
