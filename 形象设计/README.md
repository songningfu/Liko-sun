# Liko 形象与动画原型

本目录保存深圳大学校园 AI 伴生助手 Liko 的视觉设定与 H5 动画原型。

## 已确认设定

- Liko 是“柔软内层角色穿着完整荔枝外壳”的双层结构。
- 所有用户使用相同造型；外壳颜色与内层肤色在注册时分别随机一次并永久保存。
- 身体、手和脚始终使用同一种内层肤色。
- 每位用户只有一个 Liko；编号只按注册顺序生成，例如 `No. 000001`，与颜色无关。
- 不加入随机徽章、发卡、挂件或其他身份配饰。
- 第一版状态为：待机、学习、听歌、健身、游戏。

## 预览方法

直接使用浏览器打开 `liko-animation-demo.html` 即可。页面支持：

- 五种状态即时切换；
- 外壳颜色和内层肤色独立切换；
- 随机组合预览；
- 桌面端与手机端自适应；
- 系统“减少动态效果”设置。

当前页面是动作验证原型。正式 H5 应将角色封装为组件，并由后端返回持久化的颜色和注册顺序编号；浏览器端不得重新生成用户的正式身份数据。
