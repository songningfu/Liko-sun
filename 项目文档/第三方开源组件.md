# 第三方开源组件

本项目可以商业使用，但正式发布和部署前仍需保留所使用开源组件的许可证与版权声明，并在升级依赖时重新核对许可证。

## 长期记忆

| 组件 | 用途 | 许可证 | 使用方式 |
| --- | --- | --- | --- |
| [Mem0 OSS](https://github.com/mem0ai/mem0) | 提取、更新、搜索和删除登录用户的长期记忆 | Apache License 2.0 | 作为 Python 依赖嵌入 Liko FastAPI，自托管，不使用 Mem0 云端 |

当前方案不复制或修改 Mem0 源码，只通过其公开 Python 接口连接自有模型与 PostgreSQL/PgVector。若未来分发包含 Mem0 的安装包或镜像，应一并提供 Apache 2.0 许可证，并保留上游版权与 NOTICE 信息（如上游发行物包含 NOTICE）。
