# Liko 跨电脑接续开发指南

> 最后更新：2026-08-13
> 当前仓库：`https://github.com/songningfu/Liko-sun.git`

这份文档用于换电脑、交接给其他开发者，或让新的 AI 编程助手快速接着开发。它记录的是当前已确定的产品方向、已完成内容、目录入口、运行方式、安全边界和推荐的下一步。

## 1. 在另一台电脑开始工作

### 当前主工作区

- 本机后续只在团队 GitHub 克隆目录 `D:\Liko-sun` 中继续开发。
- `D:\Liko-sun-main` 仅作为本次整合前的临时备份，不再继续修改；其他电脑的目录位置可以不同。
- 不要同时在两个副本里开发，否则很容易遗漏文件或覆盖更新。

### 不会代码时的日常操作（GitHub Desktop）

开始工作前：打开 GitHub Desktop，确认当前仓库是 `Liko-sun`，点击 **Fetch origin**；如果随后出现 **Pull origin**，再点击一次。

结束工作后：先在左侧 Changes 查看本次变更，在 Summary 写一句说明，点击 **Commit to main**，最后点击 **Push origin**。

如果出现红色冲突提示、陌生的大量文件，或疑似 API Key / `.env`，先不要提交，交给开发者或 AI 助手检查。

### 第一次下载

```powershell
git clone https://github.com/songningfu/Liko-sun.git
cd Liko-sun
git switch main
git pull --ff-only
```

建议把仓库放在不含云盘同步的本地目录中。Windows 路径可以是 `E:\Liko-sun`，但代码不能依赖这个固定盘符。

### 每次开始前

```powershell
git switch main
git pull --ff-only
git status
```

只有在 `git status` 没有未处理修改时，才开始新的大范围改动。不要用 `git reset --hard` 或覆盖方式清理另一台电脑的工作。

### 每次结束后

```powershell
git status
git add <本次确实修改的文件>
git commit -m "简短说明本次完成内容"
git push
```

不要使用 `git add .` 盲目提交；先确认没有 API Key、临时文件、抓取缓存或不属于本项目的仓库。

## 3. 产品定位与已确认约定

Liko 是面向深圳大学学生的校园 AI 伴生助手。第一版是手机端 H5，不是微信小程序。

当前版本只聚焦：

1. Liko 伴生形象与五状态动画。
2. 深圳大学校园知识库问答。

社交、找朋友、找对象、匹配等功能暂不进入第一版，后续再围绕 Liko 身份体系建设。

### Liko 形象规则

- 名字固定为 `Liko`。
- 以荔枝为设计原型：外面是一层荔枝外壳，里面是角色皮肤。
- 所有用户使用同一套形状、服装结构和动画骨架；游客每次打开页面随机外壳色与肤色，注册时赠送一次自选机会。确认后配色与账号同步，未来再次换色由道具系统授权。
- 不使用随机徽章、发卡、挂件等配饰库。
- 每个用户只有一个 Liko。
- 唯一编号按用户注册顺序生成，例如 `No. 000128`；编号不带 `Liko`，也与颜色无关。
- 五种状态为：待机、学习、听歌、健身、游戏。
- 状态不允许用户手动选择。系统每 60 分钟随机切换一次，一轮内五种状态不重复；走完一轮后再重新随机，且相邻两轮边界不能出现相同状态。
- 页面必须复用 `形象设计/liko-animation-demo.html` 的正式 SVG 分层形象和动画，不能另画一个近似角色。
- 动画区域背景必须与 H5 UI 背景融合，不出现独立白色矩形底。

### 手机 H5 规则

- 底部导航只有 `Liko` 和 `我的`。
- `Liko` 默认展示角色主页，可展示年龄、人格短句、唯一编号等轻量信息，不展示等级、金币、亲密度等数值养成系统。
- 点击“问问 Liko”后在 Liko 页内部高级过渡到 Chat 界面；Chat 不是第三个底部导航页。
- 进入 Chat 后不再占用大面积展示完整 Liko，可用小头像或轻量标题。
- Chat 可展示算法推荐的高频校园问题。
- 回答需保留来源区域、复制、好评和差评；差评原因用于知识库核查和答案改进。
- 整体视觉简单、舒服、像校园生活工具，避免科技蓝紫、霓虹、机器人和强烈“AI 感”。
- 优先适配 375–430px 手机宽度，并处理 iPhone 安全区、软键盘、长文本和无横向滚动。

## 5. 本地预览方式

### 预览手机 H5

最简单的方法是直接打开：

```text
liko-h5-ui/index.html
```

更推荐在仓库根目录启动本地静态服务：

```powershell
python -m http.server 8000
```

浏览器访问：

```text
http://localhost:8000/liko-h5-ui/
```

使用浏览器手机模式重点检查 `375 × 667`、`390 × 844`、`430 × 932`。

### 预览知识审核台

启动同一个静态服务后访问：

```text
http://localhost:8000/知识审核台/
```

### 重新加工 RAG 数据

```powershell
cd 知识库\RAG加工
python process_rag.py
```

脚本只读取采集结果并写入 `output/`，不应修改原始网页和附件。运行前先阅读该目录的 `README.md`。

## 8. API Key 与隐私安全

- 曾经在聊天或截图里公开过的 API Key 一律视为已泄露，必须在对应平台撤销并重新生成。
- 不要把真实 Key 写入 HTML、JavaScript、`VITE_*`、localStorage、提交记录或日志。
- 正确链路：`手机 H5 → 自有后端 → RAG / 模型服务`。
- Key 只放在后端环境变量，例如 `DEEPSEEK_API_KEY`；仓库只提供 `.env.example` 占位，不提供真实值。
- 前端不能自由指定模型、系统提示词、输出长度或上游请求参数。
- 不采集学号、身份证、成绩、手机号等非必要敏感信息；日志默认不保存用户完整问题正文。
