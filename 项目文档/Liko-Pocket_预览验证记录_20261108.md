# Liko Pocket 预览验证记录

日期：2026-11-08。当前为无硬件的浏览器原型，以下测试不代表用户研究或硬件验收。

## 服务器与模型

- SSH 确认原 `liko-api.service` 和知识工厂正常运行，原后端在服务器 `127.0.0.1:8001` 返回健康状态。
- 新建独立的 `liko-pocket-preview.service`，仅监听服务器回环地址的 8012 端口，通过 SSH 隧道在当前电脑的 `http://localhost:8012/pocket/` 试用。
- Pocket 使用独立 SQLite、会话密钥和试用账号，不读取原账号、对话或 Mem0 用户记忆。
- 原 DeepSeek 整理调用返回 402 余额不足；改为复用现有硅基流动凭据，`Qwen/Qwen2.5-7B-Instruct` 完成整理。语音识别使用同服务的 `FunAudioLLM/SenseVoiceSmall`。
- 模型凭据只在服务器内存读取，不输出、不复制到开发电脑、不进入仓库。

将正确原文提交到整理接口，返回 `ready`，识别为待办：“把访谈提纲发给老师”，时间表述：“周五之前”；保存加整理约 5.8 秒。随后按“访谈”检索命中原记录。原始文字始终保留，未将相对时间推算为未经确认的日期。
